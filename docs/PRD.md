# BlockBoard — Product Requirements Document

## 1. Обзор продукта

### 1.1 Название
**BlockBoard** — игра слов от *Blockchain* + *Blackboard* (LMS-система СПбГУ, выведенная из строя после взлома в 2025 году).

### 1.2 Назначение
Веб-сайт для размещения транскрибированных и суммаризированных записей лекций по дисциплине **«Технология блокчейн в экономике и финансах»** (СПбГУ). Сайт предоставляет студентам удобный доступ к материалам курса и включает AI-ассистента для ответов на вопросы по содержанию лекций.

### 1.3 Целевая аудитория
- Студенты курса «Технология блокчейн в экономике и финансах» СПбГУ
- Преподаватель дисциплины (для оценки задания)
- Любые заинтересованные лица (сайт полностью открытый)

### 1.4 Ключевые ценности
- Удобный доступ к материалам лекций в любое время
- AI-помощник для быстрых ответов по материалам курса
- Визуально впечатляющий дизайн, отражающий тематику блокчейна и связь с СПбГУ

## 2. Функциональные требования

### 2.1 Структура страниц

| Страница | Описание |
|---|---|
| **Главная** | Лендинг с анимацией блокчейна, навигация к лекциям и боту |
| **Список лекций** | Каталог всех лекций с превью, датой, ключевыми темами |
| **Страница лекции** | Полный текст суммаризированной транскрипции конкретной лекции |
| **Чат-бот (AI-ассистент)** | Встроенный виджет для вопросов по материалам курса |

### 2.2 Главная страница
- Анимированный hero-блок с визуализацией блокчейна (связанные блоки/цепочки)
- Краткое описание курса и назначения сайта
- Быстрый доступ к последним лекциям
- Навигация к основным разделам
- Элементы фирменного стиля СПбГУ (цвета, отсылки)

### 2.3 Каталог лекций
- Список/сетка карточек лекций
- Каждая карточка: номер лекции, название/тема, дата, краткое содержание
- Поиск по лекциям (полнотекстовый)
- Фильтрация/сортировка по дате, теме

### 2.4 Страница лекции
- Суммаризированная транскрипция лекции в читаемом формате
- Оглавление/навигация по разделам внутри лекции
- Ключевые термины с выделением (подсветка)
- Ссылки на связанные лекции (предыдущая/следующая)
- Возможность копирования текста

### 2.5 AI-ассистент (чат-бот)
- Встроенный чат-виджет, доступный с любой страницы (плавающая кнопка)
- RAG-система: ответы основаны на содержании лекций
- Контекст: при открытии на странице лекции — автоматически учитывает текущую лекцию
- API: OpenRouter с моделью DeepSeek (или аналогичная бюджетная модель, ~$3 бюджет)
- Ограничение: индикация, что ответы основаны на материалах курса и могут быть неточными

### 2.6 Поиск
- Полнотекстовый поиск по всем лекциям
- Результаты с подсветкой найденных фрагментов
- Поиск работает на клиенте (без серверной части для простоты)

### 2.7 Глоссарий терминов
- Словарь ключевых терминов блокчейна из материалов курса
- Каждый термин: определение + ссылки на лекции, где он упоминается
- Навигация по алфавиту
- Всплывающие подсказки (tooltips) при наведении на термин в тексте лекции

## 3. Нефункциональные требования

### 3.1 Дизайн и UX

#### Визуальный стиль
- **Тема**: Тёмная основа с элементами блокчейн-эстетики
- **Цветовая палитра**:
  - Основной фон: тёмно-синий / тёмно-серый (#0a0e1a — #1a1f36)
  - Акценты: голубой/синий СПбГУ (#0055a5), бирюзовый (#00d4aa), фиолетовый (#7c3aed)
  - Текст: белый и светло-серый
- **Элементы СПбГУ**: цветовая гамма университета, возможно логотип/герб в футере
- **Шрифты**: современная гарнитура (Inter, JetBrains Mono для кода/терминов)
- **Анимации**:
  - Hero-блок: анимированная цепочка блоков (CSS/Canvas)
  - Плавные переходы при скролле (scroll animations)
  - Hover-эффекты на карточках
  - Частицы/сетка на фоне (subtle, не отвлекающие)

#### Адаптивность
- **Mobile-first** подход
- Полноценная работа на всех устройствах: телефоны, планшеты, десктоп
- Breakpoints: 320px, 768px, 1024px, 1440px
- Адаптивная навигация (гамбургер-меню на мобильных)

### 3.2 Производительность
- Статическая генерация страниц (SSG) для максимальной скорости
- Lighthouse score: 90+ по всем метрикам
- Оптимизированные шрифты и изображения
- Lazy loading для тяжёлых анимаций

### 3.3 Доступность (a11y)
- Семантическая HTML-разметка
- Достаточный контраст текста
- Навигация с клавиатуры
- ARIA-атрибуты для интерактивных элементов

### 3.4 Язык
- Интерфейс полностью на русском языке
- Контент лекций на русском языке

### 3.5 Доступ
- Полностью открытый, без авторизации
- Никаких персональных данных не собирается

## 4. Технический стек

### 4.1 Frontend
| Технология | Обоснование |

| **Next.js 14+ (App Router)** | SSG, маршрутизация, оптимизация изображений, удобная разработка |

| **Tailwind CSS** | Быстрая стилизация, адаптивность, кастомная тема |
| **Framer Motion** | Анимации (hero-блок, переходы, scroll-эффекты) |
| **next-mdx-remote** или аналог | Рендеринг контента лекций из markdown/MDX |

### 4.2 Контент
| Формат | Описание |
|---|---|
| **Markdown (.md)** | Текст лекций хранится в markdown-файлах в репозитории |
| **Frontmatter (YAML)** | Метаданные: название, дата, ключевые слова, порядковый номер |
| **JSON** | Глоссарий терминов — JSON-файл с определениями |

Пример структуры markdown-файла лекции:
```markdown
---
title: "Основы блокчейна и распределённых реестров"

keywords: ["блокчейн", "распределённый реестр", "консенсус", "хеширование"]
---

# Основы блокчейна и распределённых реестров

## Введение
...
```

### 4.3 AI-ассистент (RAG)
| Компонент | Технология |
|---|---|
| **LLM API** | OpenRouter (DeepSeek или аналогичная бюджетная модель) |
| **Векторный поиск** | Клиентский поиск по чанкам лекций (без отдельной vector DB для простоты) |
| **Архитектура** | Next.js API Route → OpenRouter API с контекстом из лекций |

**Как работает RAG:**
1. При сборке сайта лекции разбиваются на чанки и индексируются
2. При вопросе пользователя: поиск релевантных чанков по ключевым словам / embedding-based
3. Релевантные чанки отправляются как контекст в LLM вместе с вопросом
4. LLM генерирует ответ на основе материалов курса

**Бюджетное решение (~$3):**
- API-ключ OpenRouter
- Модель: DeepSeek-V3 или аналогичная (низкая стоимость за токен)
- Rate limiting на клиенте для контроля расходов

### 4.4 Хостинг и деплой
| Параметр | Значение |
|---|---|
| **Хостинг** | Vercel (бесплатный план) — лучшая интеграция с Next.js |
| **CI/CD** | Автодеплой при push в main-ветку |
| **Домен** | Vercel-поддомен (blockboard.vercel.app) или кастомный домен при необходимости |

## 6. Дизайн-концепция

### 6.1 Мудборд
- **Атмосфера**: Технологичный, серьёзный, но не скучный. Сочетание академичности СПбГУ и футуристичности блокчейна.
- **Референсы**: Crypto-дашборды, университетские порталы нового поколения
- **Блокчейн-метафора**: Каждая лекция = блок в цепочке. Визуально лекции связаны друг с другом, как блоки в блокчейне.

### 6.2 Ключевые визуальные элементы
1. **Анимированная цепочка блоков** на главной — каждый блок содержит номер лекции
2. **Сетка/граф связей** на фоне — тонкие линии, соединяющие точки (напоминает P2P-сеть)
3. **Карточки лекций** с эффектом свечения при наведении (glow effect)
4. **Хеш-стилизация** — даты или идентификаторы лекций стилизованы под хеши
5. **Цвета СПбГУ** — тёмно-синий (#003366) как один из основных цветов, перекликающийся с университетским брендом

### 6.3 Типографика
- **Заголовки**: Inter Bold / Space Grotesk
- **Основной текст**: Inter Regular
- **Код/термины**: JetBrains Mono
- **Размеры**: масштабируемая типографическая шкала (clamp())

## 8. Ограничения и допущения
- Контент лекций будет добавляться постепенно по мере готовности транскрипций
- Бюджет на AI-ассистента ограничен (~$3 на OpenRouter)
- Сайт полностью статический, кроме API Route для чат-бота
- Без серверной БД — весь контент хранится в файлах репозитория
- На этапе разработки будут использованы демо-лекции для тестирования
